# 종로M READING WORKBOOK 제작기

이 프로그램은 **영어 지문 워크북 제작만** 합니다. WEEKLY TEST, SIMUL TEST, VOCA 기능은 포함하지 않습니다.

## 실행

Node.js 20 이상을 설치한 뒤, 이 폴더에서 실행하세요.

```bash
npm install
export OPENAI_API_KEY="본인의_API_키"
npm start
```

Windows PowerShell에서는 `export` 대신 `$env:OPENAI_API_KEY="본인의_API_키"`를 사용합니다. 브라우저에서 `http://localhost:3000`에 접속하세요.

Render에서는 이 폴더 내용을 저장소 최상위에 올리고 **Node 웹 서비스**로 만드세요. Build Command는 `npm install`, Start Command는 `npm start`입니다. 환경변수 `OPENAI_API_KEY`를 등록하세요. 기존 Python 앱 저장소를 그대로 사용할 경우에는 서비스의 런타임과 저장소 구성을 Node용으로 바꿔야 합니다.

선택 환경변수: `OPENAI_WORKBOOK_MODEL`(기본 `gpt-5-mini`), `OPENAI_IMAGE_MODEL`(기본 `gpt-image-2.5-flare`). 이미지 모델은 `2016x672` 크기의 **가로 3:1** 출력과 이미지 참조 편집을 지원해야 합니다. 이전 배포에서 `OPENAI_IMAGE_MODEL=gpt-image-1-mini`를 지정했다면 이 값을 제거하거나 가로형 출력을 지원하는 모델로 바꾸세요. API 키는 서버에만 두며 브라우저에 입력하지 않습니다.

## 제작 순서

1. 처음부터 보이는 **1문단·2문단 입력 칸**에 영어 지문을 각각 넣습니다. 문단이 더 있으면 **+ 문단 추가**를 누르세요. 2문단이 비어 있으면 무시합니다. 각 칸의 빈 줄은 문단 구분으로 처리하지 않으므로 모의고사 지문 하나는 1문단 칸에만 넣으면 됩니다. 각 칸에서 PDF, DOCX, TXT, MD 파일을 불러올 수도 있습니다. 여러 문단이 든 파일은 문단별 칸에 나누어 주세요.
2. 소제목이 있으면 각 문단의 소제목 칸에 쓰고, 가지고 있는 한국어 해석은 해당 문단 옆 칸에 문장 순서대로 넣습니다. 해석을 비운 문단은 AI가 작성합니다.
3. **워크북 생성**을 누릅니다. 문단 분석은 최대 3개, 삽화는 최대 4개를 동시에 처리합니다. 완성된 문단의 그림을 다른 문단 분석과 겹쳐 생성합니다. 글 미리보기가 먼저 나타나고 삽화가 채워집니다.
4. 완성되면 **학생용 PDF 저장**과 **교사용 PDF 저장**을 각각 눌러 브라우저 인쇄 대상에서 **PDF로 저장**을 선택합니다. 삽화가 일부 실패하면 **삽화 재시도**를 누릅니다.

## 워크북 구성

- **READING:** 원문과 해석을 문장마다 넓은 간격으로 배치합니다. 각 페이지의 2~3문장에 맞는 **가로 3컷 만화와 짧은 한국어 그림 설명**을 넣고, **각 문단의 마지막 페이지에는 ‘주제 (Topic)’와 ‘제목 (Title)’의 가로 전체 작성 칸**을 각각 둡니다. 한 문장짜리 문단은 한 문장만 배치됩니다.
- 실제 입력이 1문단뿐이면 학생용과 교사용에서 **‘Paragraph 1’ 표시 없이** 연속된 한 지문으로 보여 줍니다. 2문단 이상이면 문단별 표시가 나옵니다.
- **STEP 1:** 모든 문장의 해석, 문장 사이 논리 관계 빈칸, 문단별 내용확인과 한국어 O/X.
- **STEP 2:** 모든 문장에 단어 빈칸 2~3개.
- **STEP 3:** 모든 문장의 어법 선택과 근거 작성 두 줄.
- **STEP 4:** 문단 나열. 원문이 한 문단이면 연속 구간으로 나누어 배열합니다.
- **STEP 5:** 문장 나열.
- **교사용:** 문장별 해석·빈칸·어법 근거·연결 설명, 내용 문항과 나열 정답.

## 시그니처 캐릭터와 그림 기준

`assets/reading_style_reference.jpg`와 `assets/reading_characters_reference.jpg`는 사용자가 제공한 예시 PDF의 READING 그림입니다. 프로그램은 매 삽화 생성 요청에 **두 그림을 함께 참조**합니다. 동그란 안경, 작은 갈색 앞머리와 갈색 재킷·청록색 넥타이의 안내자, 짙은 갈색 단발·노란 재킷의 안내자 두 명을 같은 캐릭터로 유지하라는 지침을 적용합니다. 3:1 가로형 그림 안에 **동일한 크기의 세 컷**을 왼쪽부터 그리도록 요청하고, 페이지 인쇄 화면에서도 컷 경계를 3등분으로 표시합니다. 참고 그림의 전쟁 장면 등은 새 지문과 관련 있을 때에만 그리도록 제한합니다.

삽화는 READING에만 들어갑니다. 생성형 이미지의 세부 외형과 장면 묘사는 매번 달라질 수 있으므로 인쇄 전 확인하세요. 누락된 삽화는 **삽화 재시도**로 다시 요청할 수 있습니다. 서버 재시작 시 작업 결과와 삽화가 사라지므로 PDF 또는 초안 JSON을 저장해 두세요. 긴 지문은 삽화 장수에 따라 생성 시간이 늘어납니다.

검증은 `npm test`로 실행합니다.
